# CLAUDE.md — docs/reboot-kit/ (archive folder)

This folder holds the **session-loading kit** and **historical material**: old Smart
Prompts (`SmartPrompts/`), past summaries, notes and reference tables. Most files here
are **snapshots**: they describe the framework as it was when they were written.

**Nothing in this folder is an authority on the live framework.** Read, in this order:

1. **HEAD** — the committed state of `main`
   (`https://raw.githubusercontent.com/Echopraxium/tscg/main/…` or `git show HEAD:<file>`).
   Live ontologies live under `ontology/` (M3/M2/M1) and `instances/` (M0) — never here.
2. **`TSCG_ReferenceCorpus_Bootstrap.md`** (this folder) — the hard invariants.
3. **`TSCG_ReferenceCorpus.md`** (this folder) — where each authority lives.
4. The repository-root **`CLAUDE.md`**.

Live files of this folder: `TSCG_SmartPrompt.md` (session loader),
`TSCG_ReferenceCorpus_Bootstrap.md`, `TSCG_ReferenceCorpus.md`, `TSCG_FileTree.md`
(generated by `tscg_generate_filetree.py`). Everything else is history.

Never copy a live ontology (`.jsonld`/`.ttl`) into this folder: a frozen copy that
looks like a source is how stale content gets mistaken for the real thing. All the
ontology files that used to sit here were removed on 2026-10-03 (Michel: obsolete and a
source of errors): stale copies of M2_GenericConcepts, M3_EagleEye, M3_SphinxEye and
M0_VSM, the dead M3_GenesisSpace and old M2 MetaConcepts files, the
M2_FormulasReference_v15.10.0.json table, and a duplicate of
docs/papers/inputs/00_M3_Philosophical_Basis_Sketch.jsonld (it caused duplicate IDs in
the RAG build).

This file replaces a stale guide (GenesisSpace, tensor products, "68 metaconcepts"…)
that Claude Code loaded automatically when working in this folder (2026-10-03).
